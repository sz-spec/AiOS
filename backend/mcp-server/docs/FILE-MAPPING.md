## 🚀 Quick Setup Commands

### Option 1: Using the organize script
```bash
# Download all files to a folder called 'claude-outputs'
# Then run:
chmod +x organize-project.sh
./organize-project.sh ./claude-outputs ./v-os-mcp-agent-server
```

### Option 2: Manual setup
```bash
# Create project directory
mkdir -p v-os-mcp-agent-server
cd v-os-mcp-agent-server

# Create directory structure
mkdir -p src/{orchestration,framework/{caching,quotas},observability}
mkdir -p docs scripts k8s monitoring
mkdir -p .github/{workflows,ISSUE_TEMPLATE}
mkdir -p tests/{unit,integration}

# Copy files manually according to the mapping above
# Then:
npm install
cp .env.example .env
npm run dev
```
