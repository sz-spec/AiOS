# השוואת 11 מקורות VOS והחלטות איחוד

תאריך: 2026-09-13. הושלמה השוואת תוכן של כל 11 העצים הקיימים מול `vos 5`, כולל קבצים שלא נשמרו ב־Git ושינויים מול HEAD. אין בכך הוכחה שכל היכולות מוזגו או פועלות.

| התוכן אינו נמצא ב־VOS 5 | 824 | רשימת החלטות פתוחות; כוללת קוד, תיעוד ותלויות צד שלישי |

בסך הכול 6,239 נתיבים ב־43 רכיבים. ב־1,806 נתיבים קיימת לפחות גרסת מקור שלא נשמרה כתוכן זהה; 2,899 גרסאות תוכן ייחודיות כאלה דורשות הכרעה או אימות. זו אינה ספירת יכולות חסרות.

מבין הנתיבים החסרים, 335 שייכים לעץ ה־bootloader ו־248 לתיעוד. אין להציג אותם כ־583 תכונות מערכת הפעלה שאבדו. ההחרגות כוללות תוצרי בנייה, תלות מותקנת, נתוני ריצה, סודות וקישורים שלא נעקבו; הן רשומות לכל מקור. תבניות `.env.example` ו־`.env.template` נכללו בהשוואת hashes בלבד.

## ההכרעות המרכזיות

- הקרנל הקנוני נשאר בסיס האיחוד: נשמרים תיקוני האתחול, המעבדים, הזיכרון והמעבר בין מרחבי כתובות. אין חזרה למימושי CR3 גלובליים ישנים.
- מודול PCID הישן אינו נבחר כהחלפה מוכנה; הוא מצהיר בקוד על שלד ללא שימוש בנתיב הריצה. אופטימיזציית PCID נשארת יעד פתוח.
- לוגיקת מכסות OOM ומדיניות תעבורה מ־VOS3-Cyber נבחרו כמועמדות להסבה, בתנאי חיבור לנתיבי ההקצאה והרשת האמיתיים ושמירת בידוד והרשאות.
- ECAM הקנוני נשאר המימוש היחיד; הליכוני יכולות PCI מהמקור vos/vos4-track-2 הם תוספות לבדיקה, ולא דרייבר נוסף להעתקה מקבילה.
- ניהול צי, יומן MMR, Blueprint deployments, snapshots, idempotency ולקוח Windows זוהו כמועמדים מפורשים שטרם שולבו במלואם.
- שלדי VBS/attestation ו־Hyper-V loopback אינם נחשבים לתמיכת חומרה או Windows עובדת.
- תוספות VOS3 נושאות בחלקן רישיון Sovereign נפרד; בחירתן מחייבת שימור ובדיקת תנאי הרישיון, ללא שינוי תווית ל־MIT.

## כיצד ממשיכים מההשוואה

לכל רכיב נבחר בסיס אחד ונשמרה רשימת הגרסאות הפתוחות. בשלב המימוש יש להסב יכולות חסרות אל אותו בסיס, להכריע בהבדלים שנותרו, להריץ בדיקות התנהגות ולעדכן את היומן. לא בוצעה העתקת קוד עיוורת ולא שונו עצי המקור במסגרת ההשוואה. שינויי SMP שנותרו ב־working tree קדמו למשימה זו.

שחזור ההשוואה והבדיקות:

```sh
python3 consolidation/reconcile_sources.py
python3 -m unittest discover -s consolidation -p 'test_*.py'
```

עשר בדיקות עברו, כולל בדיקות סריקה, החרגות, זיהוי שינוי/מחיקה/קובץ חדש מול Git אמיתי, מאגר ללא HEAD ובדיקת חשבונאות מלאה של המקורות והרכיבים. בדיקות אלה מאמתות את כלי ההשוואה; הן אינן בדיקות תפעול של המערכת המאוחדת.
