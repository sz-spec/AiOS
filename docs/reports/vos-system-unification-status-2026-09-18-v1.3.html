עבודות פתוחות בגל הליבה

  1. משולב, אימות פתוח: שער CPU מוקדם וחוזה CPUID אחיד שולבו בחמישה נתיבים. QEMU עבר; direct EFI ו־AP שלילי עדיין פתוחים.
  2. ai_oom.c — primitive מכסה עמיד ל־replay/ABA שולב ואומת; נשאר לחברו ל־AI Guard ול־KV עם region pins, deferred reclaim, cancellation בטוח ובעלות פיזית.
  3. exec_syscall.c — הקשחת clone/TID מוזגה; תיקון brk() נשאר פתוח עד קיום transaction של בעלות כתובות ו־fault.
  4. test_pcr_stability.c — נדרש ניסוי PCR/TPM אמיתי; בדיקת host אינה מוכיחה יציבות מדידה.
סטטוס כלל המקורות: אין עוד נתיב חסר או שונה ללא החלטה. בסיכום שני הגלים: 1,566 בחירות מקור סגורות, 28 במימוש, 6 משולבות באימות, 29 בניסוי ו־20 בשער משפטי.
החלטה בטיחותית: שני אבות טיפוס לתיקון brk() נדחו לאחר ביקורת. rollback לפי כתובת עלול למחוק מיפוי זר במרוץ, ומעבר ל־demand paging אינו אטומי מול page fault. לא מוזג תיקון שמציג מעבר מלאכותי.

השלבים שנותרו

P0 — סגירת ליבה ואיחוד סמנטי

  1. לבנות API אטומי של address-space claim/commit/no-replace ובעלות משותפת ל־heap, ‏VMA ו־SHM; לאחר מכן לתקן brk() עם fault injection ומרוצי SMP.
  2. להשלים רישום משימות דו־שלבי ולבדוק clone/pthread/fault/exit על SMP, כולל כשל בכל נקודת פרסום.
  3. להשלים את אימות preflight ב־direct EFI וב־AP שלילי; לסגור AI OOM ו־PCR stability באמצעות ניסויים אמיתיים.
  4. לממש 28 נתיבים פתוחים, להשלים אימות ל־6, להריץ 29 ניסויים ולהכריע 20 שערי רישוי; המיפוי עצמו הושלם.
  5. לסגור את אבחון SPSC בלי להוריד סף ובלי להסתיר ריצות שנכשלו.

P1 — קבלה מערכתית

  1. בנייה מ־checkout נקי בפקודה אחת ויצירת BIOS/UEFI ISO מאותו commit.
  2. מטריצת 1/4 CPU: אתחול, זיכרון, מתזמן, user program, fork/exec, IPC, revocation ו־crash/reap.
  3. בדיקות בידוד עוינות בין תהליכים, ליבה, SHM ו־DMA; אימות KPTI ו־TLB תחת SMP.
  4. התקנה וחזרה לאחר reboot על לפחות שתי מכונות פיזיות שונות; AHCI/NVMe, USB, NIC, ACPI/APIC ו־UEFI/legacy.
  5. מצב hosted מלא ב־Windows, macOS ו־Linux עם VBus וזהות אחידים; AI מקומי ב־air-gap.

P1 — שרשרת שחרור

  • release candidate יחיד מ־commit/tag חתום; תוצרי אבחון מופרדים בשם ובגיבוב.
  • SBOM, locks, סריקות, signing, provenance ו־artifact manifest מאותה ריצה.
  • שחזור byte-identical אצל builder בלתי תלוי, עם גרסאות כלים ולוגים מלאים.
  • אין הכרזת תאימות או אבטחה מעבר לחומרה ולתרחישים שנבדקו בפועל.
